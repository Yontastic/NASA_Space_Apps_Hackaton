Fórmula de Similitud Gaussiana Multivariada

Cada candidato se evalúa contra las variables del objetivo planetario mediante una función de decaimiento cuadrático normalizado:

s_i = exp(-0.5 * sum(w_k * (Δx_k / τ_k)²))

Δx_k (Diferencia Absoluta): Desviación entre la medición del terreno terrestre y la media del objetivo planetario.

τ_k (Vector de Tolerancia): Rango admisible específico por variable (p. ej. 5.0° para pendiente, 0.15 para albedo).

Cumplimiento ODS 14 y 15: Clasificación de impacto ético y ambiental de acuerdo con la base de datos mundial de áreas protegidas (WDPA).
